## In short

The GitHub template every new repository under `izam-mohammed` starts from
(`gh repo create ... --template izam-mohammed/repo-template`). It carries
the security baseline: the shared security gate, Dependabot, pre-commit
hooks, a `.gitignore` that keeps secrets out, and `SECURITY.md`. It is
Python-flavoured by default and has no lint, test, coverage, README or
site skeleton for the new repository.

## What a person can use

### Starting a repository

- Create a repository from it with `gh repo create` and `--template`
  (`README.md`; marked as a template on GitHub, `is_template: true`).
- The security gate on every PR and weekly, pinned at `ce1b7cc` of
  `izam-mohammed/.github`, `ecosystem: python` by default
  (`.github/workflows/security.yml`; commit `426e211`).
- Dependabot for `uv` and GitHub Actions, weekly
  (`.github/dependabot.yml`; commit `6afe3ec`).
- pre-commit: gitleaks, private keys, large files, merge and case
  conflicts, whitespace, ruff check and format (`.pre-commit-config.yaml`).
- A `.gitignore` for secrets, Python, Node and editor files (`.gitignore`).
- A vulnerability reporting policy and the "rotate first" rule
  (`SECURITY.md`).
- A README in the house voice explaining all of it (`README.md`; commit
  `a6eebcc`).

## Under the hood

- **Shape**: configuration files only, no code.
- **Data**: none.
- **Integrations**: the reusable gate in `izam-mohammed/.github`.
- **Standards and CI**: the security gate only; no check command
  (`docs/standards.md`, `.github/workflows/security.yml`).
